# 关键运行流程

## 启动与入口选择

```mermaid
flowchart TD
    S["进程启动"] --> C["安装 crash handler / tracing"]
    C --> P["解析 CLI 参数与环境"]
    P --> M{"运行模式"}
    M -->|默认| T["初始化终端与 Pager"]
    M -->|headless| H["run_headless"]
    M -->|stdio| A["run_stdio_agent / ACP"]
    M -->|leader| L["run_leader"]
    M -->|workspace| W["workspace 管理/服务"]
    T --> CFG["加载有效配置与凭据"]
    H --> CFG
    A --> CFG
    L --> CFG
    W --> CFG
    CFG --> RUN["装配 Agent、Tool Registry、Workspace、Telemetry"]
```

## 一次 Agent 回合

```mermaid
sequenceDiagram
    actor U as 用户/宿主
    participant UI as Pager/ACP/Headless
    participant S as Grok Shell
    participant C as Chat State Actor
    participant A as Agent
    participant P as Sampler
    participant T as Tool Runtime
    participant W as Workspace/MCP

    U->>UI: 提交 prompt
    UI->>S: Prompt + 会话上下文
    S->>C: 追加用户消息
    S->>A: 构建本回合 prompt/toolset
    A->>P: 流式采样请求
    loop 模型事件流
        P-->>S: text/reasoning/tool-call/usage
        S-->>UI: 增量显示
        alt 工具调用
            S->>T: resolve + invoke(call_id, args, context)
            T->>S: 权限请求（如需要）
            S->>UI: 请求审批
            U-->>UI: allow/deny
            UI-->>S: 权限决定
            T->>W: 执行本地或远程工具
            W-->>T: partial/final/error
            T-->>S: 工具结果
            S->>C: 记录工具调用与结果
            S->>P: 继续采样
        end
    end
    S->>C: 完成回合、usage、状态
    S-->>UI: 完成/失败/取消
```

## 工具解析与调用

```mermaid
stateDiagram-v2
    [*] --> Received
    Received --> Rejected: Schema/Scope 无效
    Received --> Resolving
    Resolving --> Missing: 未注册或连接不可用
    Resolving --> Approval: 命中权限策略
    Resolving --> Running: 无需审批
    Approval --> Running: 允许
    Approval --> Denied: 拒绝/超时
    Running --> Streaming: 有 partial result
    Streaming --> Running
    Running --> Succeeded
    Running --> Failed
    Running --> Cancelled: 取消传播
    Missing --> [*]
    Rejected --> [*]
    Denied --> [*]
    Succeeded --> [*]
    Failed --> [*]
    Cancelled --> [*]
```

调用身份由 Tool Context 携带，工具解析按 `ToolId/Scope/Capabilities` 选择 Local、Hub 或 MCP transport。UI 隐藏不是授权；最终拒绝必须发生在执行端口。

## 会话状态与压缩

```mermaid
flowchart LR
    MSG["消息/工具结果"] --> LEDGER["Chat State + Usage Ledger"]
    LEDGER --> CHECK{"接近上下文预算？"}
    CHECK -->|否| NEXT["下一次采样"]
    CHECK -->|是| SELECT["选择待压缩 turn"]
    SELECT --> CP["生成 compaction prompt"]
    CP --> MODEL["CompactionSampler"]
    MODEL --> SUMMARY["摘要 + 保留项"]
    SUMMARY --> TRANS["记录压缩转录与边界"]
    TRANS --> NEXT
```

压缩不是删除审计事实：活跃 prompt 使用压缩视图，持久化层仍需保留足以解释压缩来源的元数据；具体保留策略由配置和代码版本决定。

## ACP 嵌入流程

```mermaid
sequenceDiagram
    participant IDE as ACP Client
    participant G as xai-acp-lib Gateway
    participant S as Shell ACP Adapter
    participant A as Agent Session
    IDE->>G: initialize
    G->>S: 规范化 capability/client info
    S-->>IDE: capabilities
    IDE->>G: session/new 或 session/load
    G->>A: 创建/恢复会话
    A-->>IDE: session update
    IDE->>G: prompt
    G->>A: 驱动回合
    A-->>IDE: content/tool/plan updates
    A-->>IDE: stop reason
```

stdio 以逐行消息 framing；`xai-acp-lib` 负责通道、读取和消息规范化，Shell 负责 ACP 语义映射，Agent 不直接依赖编辑器。

## 文件变更归因

```mermaid
flowchart TD
    F["文件系统原始事件"] --> N["fsnotify 去抖/语义化"]
    N --> H["Hunk Tracker Actor"]
    H --> G["读取 Git 状态与 diff"]
    G --> O{"与 Agent 操作窗口匹配"}
    O -->|匹配| AA["Agent-attributed hunk"]
    O -->|不匹配| EA["External-attributed hunk"]
    AA --> UI["Pager 变更展示/遥测"]
    EA --> UI
```

## 取消与关停传播

```mermaid
flowchart LR
    SRC["Ctrl-C / ACP cancel / UI stop / shutdown"] --> TOK["CancellationToken"]
    TOK --> SAMPLE["停止模型流"]
    TOK --> TOOL["取消工具 future"]
    TOK --> PROC["终止进程组"]
    TOK --> UI["结束 spinner/恢复输入"]
    TOK --> SAVE["提交可安全保存的会话状态"]
```

取消是协作式的；已经提交到外部系统的副作用不能靠丢弃 Future 撤销，必须查询结果或补偿，详见可靠性说明书。
