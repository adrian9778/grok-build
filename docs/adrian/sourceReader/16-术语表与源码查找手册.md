```
问：内置工具在哪？
  → 源码查找手册: 概念=「内置工具」 → crates/codegen/xai-grok-tools/src/implementations/grok_build/
问：工具要满足什么接口？
  → 术语表: Tool trait = 一种工具的「身份+描述+入参+出参+执行」
  → 源码查找手册: Tool 在 xai-tool-runtime/src/tool.rs:36
问：它怎么被模型调用到？
  → 术语表: ToolDispatch = 对象安全派发契约
  → 源码查找手册: dispatch.rs:32；聚合点 CompoundResolver resolver.rs:215
问：执行前要过什么？
  → 术语表: 权限双层 / OS 沙箱
  → 源码查找手册: PermissionManager manager/mod.rs:1404 / SandboxManager sandbox/lib.rs:159
```

一张表即可从「想法」走到「具体文件」。

### 4.3 常用 grep 起手式（在你自己的探索里）

```bash
# 找某个 trait / 结构定义
grep -rn "pub trait ToolDispatch" crates/
grep -rn "pub struct SessionLiveState" crates/

# 找某个符号被谁用
grep -rn "ToolDispatch::call" crates/

# 找某概念所在 crate（目录级）
find crates -type d -iname '*permission*'

# 确认版本钉死
grep -n "channel" rust-toolchain.toml
```
